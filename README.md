# Invoice-Scanner---Telegram-to-Google-Sheets
An AI-powered automation that extracts invoice data from images sent via Telegram and automatically stores the structured information in Google Sheets. Built with n8n, AI, Telegram, and Google Sheets to reduce manual data entry and streamline invoice processing.
